# 🚀 PINmate

PINmate is a campus-focused web application that helps students find teammates for
projects, hackathons, research, and startups.

Built using:
- Pure HTML, CSS, and inline JavaScript
- Firebase Authentication
- Firebase Realtime Database
- Firebase Hosting

No React, no backend server — fully Firebase-powered.

---

## ✨ Features

- 🔐 Email & password authentication
- 👤 User profiles stored in Firebase Realtime Database
- 🧑‍💼 Admin panel protected via Firebase **custom claims**
- 📊 Admin dashboard (read-only, secure)
- 🎥 Demo video modal on landing page
- 📱 PWA-ready (manifest + icons)
- 🔒 Secure Realtime Database rules
